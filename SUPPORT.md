# Getting help

1. Run `claude-watch doctor`. It checks the hooks, the notifier, and the
   reminder agent, and prints recent errors.
2. Read the README, especially "Make notifications actually appear" on macOS
   and the Windows section.
3. Still stuck? Open an issue with the bug report template and paste the
   `doctor` output.

For security problems, see [SECURITY.md](SECURITY.md) instead of opening an
issue.
